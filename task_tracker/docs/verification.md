# Протокол локальной проверки

Проверено 7 ноября 2026 года.

| Проверка | Результат |
|---|---|
| `docker compose -p specdb-tracker --profile tools run --build --rm tests` | 37 passed на PostgreSQL 16 |
| Alembic metadata check | Входит в пройденный интеграционный тест |
| Alembic upgrade → downgrade → upgrade | Пройдено на отдельной временной БД |
| Docker Compose build / up --wait | Образ собран, контейнер healthy |
| `python -m scripts.demo` внутри контейнера | CRUD, фильтры, аналитика, logout пройдены через HTTP |
| Контрольная статистика | 12 задач, 6 завершены, 50% |

Тесты запускались в Docker на Python 3.11/Linux arm64 и настоящей PostgreSQL 16.
Каждый интеграционный тест использовал свою БД `tracker_test_<uuid>` с миграциями.
Набор зависимостей сохранён в `requirements.lock`. Starlette выдаёт одно
предупреждение об устаревании интеграции TestClient с httpx; на результат тестов
оно не влияет. GitHub Actions подготовлен, но удалённый запуск здесь не выполнялся.

Старые PostgreSQL/MongoDB/Redis лабораторные не изменялись и не перезапускались.

Название проекта и архива: «Чернов Илья — Итоговое задание — Трекер задач».
Архив проверен на целостность, не зашифрован. Загрузка в LMS и публикация
в GitHub не выполнялись; внешний доступ к материалам должен быть проверен
после прикрепления файла или публикации репозитория.
