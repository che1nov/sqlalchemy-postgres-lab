## Сценарий защиты на 5-7 минут

1. **Идея и стек (30 сек):** персональные задачи с исполнителем, темой и статусом.
2. **Модель (1 мин):** три таблицы, две роли пользователя в задаче, FK и индексы.
3. **API (2 мин):** зарегистрироваться, войти, создать задачу, назначить исполнителя,
   изменить статус, отфильтровать список, удалить временную задачу.
4. **Безопасность (1 мин):** запрос без токена → 401; задача другого аккаунта → 404;
   кавычки в поиске остаются данными; показать тесты инъекций и хеширование.
5. **Аналитика (1 мин):** группировки по статусу, теме, исполнителю; PNG-график.
6. **Тесты и запуск (1 мин):** pytest, проверка миграций, Docker, ограничения решения.

Автоматическая демонстрация: `python -m scripts.demo`. Контрольный набор:
12 задач; `done=6`, `in_progress=3`, `new=2`, `cancelled=1`; завершение 50%.
Три темы по 4 задачи; 6 задач назначены автору, 6 без исполнителя. Это синтетические
данные для проверки, а не статистика реальной команды. Вывод: половина задач
завершена, четверть в работе; распределение по темам равномерное. Из этих данных
нельзя оценить производительность или сроки без истории и временных метрик.
